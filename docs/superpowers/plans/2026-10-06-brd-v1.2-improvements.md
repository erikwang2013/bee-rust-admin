## 新接口契约（前后端必须一致）

```
# 操作日志（审计）
GET    /api/v1/audit-logs?page&size&username&module&status&start&end → Page<AuditLog>
DELETE /api/v1/audit-logs?username&module&status&start&end            → { deleted: number }
GET    /api/v1/audit-logs/export?<同上>                               → text/csv 附件

AuditLog = {
  id, admin_id, username,      // 谁
  module, action,              // 哪个模块、什么动作（如 admin / 新增管理员）
  method, path,                // 原始 HTTP 方法与路径
  status: 0|1, msg,            // 0 失败 1 成功；msg 为错误摘要或 ''
  duration_ms, ip, created_at  // created_at 形如 "2026-10-06 02:40:00"
}

# 导出（三个列表页都能导；鉴权复用各自的 list 权限码）
GET /api/v1/admins/export?<同列表筛选>      → text/csv 附件
GET /api/v1/login-logs/export?<同列表筛选>  → text/csv 附件

# 个人资料 / 头像
PUT  /api/v1/auth/profile  { nickname, email, phone } → null
POST /api/v1/auth/avatar   { data_url }               → { avatar: "/api/v1/avatar/{id}" }
GET  /api/v1/avatar/{id}                              → 图片字节（Content-Type 由扩展名决定）
```

**权限码**：新增 `system:auditlog:list`、`system:auditlog:remove`（菜单 + 两个按钮，随 seed 补齐）。
**CSV 规则**：UTF-8 BOM 开头（Excel 直接打开不乱码）；字段以 `= + - @` 开头时前置一个 `'`（防 CSV 注入）；`text/csv; charset=utf-8`。
