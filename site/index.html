项目介绍

一个把权限当正事做的后台

它解决的问题很实际：权限要细到按钮、数据要看得到范围、登录要留痕。前端隐藏只是体验，后端每个接口还会再校验一次；列表查询在数据层注入范围条件，参数化绑定，不拼接用户输入。

服务端用本仓库的 bee-rust 框架写就（axum 路由 + 自研 ORM 执行层 + INI 配置），前端是 Vite + React 18 + Ant Design 5 单页应用，两者通过统一的 {code, msg, data} 契约对接。

启动即完成建表与种子：超管、菜单权限树、8 个内置任务自动就位；升级只加列，不删列、不改类型。

  • 01

    权限细到按钮

    角色勾到按钮级权限码，如 system:admin:resetPwd；前端渲染菜单，后端逐接口校验。

  • 02

    数据范围五档

    全部 / 本部门及以下 / 本部门 / 仅本人 / 自定义；多角色取并集，一个启用的角色都没有就什么都不给看。

  • 03

    会话可强制下线

    JWT 携带 token_version：改密、禁用、登出即失效旧令牌，不依赖黑名单。

  • 04

    全程留痕

    登录成功 / 失败 / 退出，以及所有有副作用的操作都入库；四类编辑额外记录字段变更摘要。

功能设计

该有的都有，安全不是附件

从门岗到账本，从数据通道到通知出口。每个模块都带着自己的权限码与审计路径。

01 / RBAC

菜单 + 按钮两级权限

管理员 ← 角色 ← 菜单与按钮；超管旁路权限码。前端隐藏只是体验，后端每次再校验。

admin_rolerole_menurequire()
02 / SCOPE

五档数据权限

列表查询层注入部门子树、本人或自定义部门条件；多角色取并集，不拼接用户输入。

datascoperole_dept
03 / SESSION

无状态会话，强制下线

JWT 携带版本号；改密、禁用、登出即让旧令牌失效。退出其他设备一键生效。

token_versionjwt-rust
04 / AUDIT

审计与请求安全扫描

登录记录、操作日志、变更摘要；32 个攻击特征检测器，默认只留痕，可切到拦截。

login_logaudit_logsecurity-rust
05 / TOTP

动态验证码与备用码

密码验过之后才提示要码；10 枚一次性备用码只存哈希；密钥加密落库，设备列表可踢单台。

RFC 6238AES-256-GCMbackup_code
06 / JOBS

定时任务与数据库备份

8 个代码注册的内置任务：备份、附件清理、通知重投、导出执行；固定间隔调度，可手动补跑。

jobjob_logdb_backup
07 / DATA

导入、导出与附件

CSV 导入单事务全有或全无；导出中心异步执行、按代次命名；附件分片上传、内容去重、孤儿回收。

importexportattach
08 / NOTIFY

Webhook 与 SMTP

事件通知带 HMAC-SHA256 签名；失败退避重投、落账本；发送时再次封禁内网地址，不跟随重定向。

notice.publishedaccount.lockedSMTP
09 / I18N

中英双语与公开配置

界面两套文案、错误码查表；登录页与页脚的副标题、版权、项目地址读公开配置，刷新即变。

i18nconfigs/public

架构设计

五层链路，一条请求走到底

浏览器 → nginx → bee_router → Auth 提取器 → handler → bee_orm → MySQL。401 与 403 在查库之前就短路。

客户端 SPA · nginx :8081 · bee_admin · bee_orm / bee_config / bee_logs · MySQL 8.4（22 张表）。

三段式权限模型：管理员 ← admin_role → 角色 ← role_menu → 菜单与按钮；角色 ← role_dept → 部门用于自定义数据范围。

以 GET /api/v1/admins 为例的 12 步链路；校验签名、版本与账号状态后加载角色与权限码，再进入 handler。

配置强度校验 → 连接 MySQL → migrate::sync 只建表 / 加列 → 幂等补齐超管、菜单与任务 → 监听 127.0.0.1:8080 → SIGTERM 退出。

快速开始

三条命令，或者交给脚本

预编译产物需要 glibc ≥ 2.38；老机器用源码构建或 Docker，脚本会在写盘前检测并给出替代命令。

手动路径

  1. 克隆仓库
    git clone --depth 1 https://github.com/erikwang2013/bee-rust-admin.git
  2. 生成配置
    填好 [db] dsn、[jwt] secret 与 [app] encrypt_key（后者不可更换）。
  3. 起服务与前端
    cargo run -p bee_admin，再 cd admin/web && pnpm i && pnpm dev。
完整安装文档使用说明

一键安装

脚本会拉发布产物或源码构建，生成配置、建库、装 systemd + nginx，并跑自检。

# 交互式；--help 看全部参数
git clone --depth 1 \
  https://github.com/erikwang2013/bee-rust-admin.git
cd bee-rust-admin
less install.sh && bash install.sh

老机器：bash install.sh --mode build；容器：./compose-up.sh --build。
